1. Introducción

1.1 Propósito del Sistema

El Sistema de Novedades RRHH es una aplicación web moderna diseñada para digitalizar y optimizar el proceso de recolección de novedades laborales que impactan en la liquidación de sueldos.

Beneficios Clave: Precisión, trazabilidad y eficiencia en la gestión de novedades de personal.

1.2 Usuarios Objetivo

Administradores

Acceso completo a todos los tipos de novedad

Área Comercial

Acceso a novedades comerciales y operativas

Área de Producción

Acceso a novedades operativas y de producción

2. Descripción General del Sistema

2.1 Características Principales

  • Interfaz Responsive
  • Validación en Tiempo Real

2.2 Período de Vigencia

IMPORTANTE: El sistema maneja períodos mensuales fijos del día 28 del mes anterior al 27 del mes actual.
Ejemplo para agosto 2025:
Desde: 28 de julio de 2025
Hasta: 27 de agosto de 2025

5.2 Validaciones Importantes

El sistema valida automáticamente:
  • Empleado: Debe existir en la base de datos
  • Campos Obligatorios: No pueden estar vacíos
  • Fechas: Deben estar dentro del período vigente
  • Importes: Deben ser valores positivos
  • Cantidades: Horas, unidades y cortes deben ser mayores a cero

10. Resolución de Problemas

10.1 Problemas Comunes y Soluciones

Posibles Causas:
  • Conexión a la base de datos interrumpida
  • JavaScript deshabilitado
  • Filtros de firewall corporativo
Soluciones:
  1. Recargar la página (F5)
  2. Verificar conexión a internet
  3. Intentar con otro navegador
  4. Contactar al administrador del sistema

Pasos para resolver:
  1. Revisar todos los campos obligatorios
  2. Verificar que las fechas sean válidas
  3. Intentar guardar nuevamente
  4. Si persiste, contactar soporte técnico

10.2 Códigos de Error del Sistema

Código Descripción Acción Recomendada
E001 Empleado no encontrado Verificar número de legajo
E002 Tipo de novedad inválido Seleccionar tipo válido
E003 Fecha fuera de período Ajustar fecha al período vigente
E004 Permisos insuficientes Contactar administrador
E005 Error de conexión BD Reportar al soporte técnico
